# Commander 2016 Boulder deck-box labels

This folder contains both owned Commander 2016 deck tops:

- **Invent Superiority** — its newly created label design
- **Breed Lethality** — an exact reused copy of the Commander Anthology Volume II design

Breed Lethality is not a second design, but its print-ready file is duplicated into this folder so the folder contains both physical deck labels. The manifest's `reuseRenderedPath` keeps that reuse reproducible at both 1200 and 1440 DPI.
