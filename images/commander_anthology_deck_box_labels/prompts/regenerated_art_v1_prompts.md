# Regenerated commander background art v1

Generation mode: built-in OpenAI ImageGen, one call per background. Each call used the corresponding exact Commander Anthology art crop as its sole reference image.

All outputs were retained non-destructively under `../src/regenerated_art_v1/` and contain no label text or mana symbols. The deterministic Swift renderer adds those elements afterward.
